## 3. Existing Trading Logic

**唯一在跑的策略:** 收盤站上 50 日均線才持有 + 波動目標 27%
(回看 50 日)+ 逐倉槓桿 3×。

- 訊號:`rules.ma_filter`
- 規模:`rules.vol_target`
- 出場:跌破 50 日均線(**策略本身的規則,不是另挑的百分比**)
- 交易池:寫死 7 幣(主城)/ 動態 23 幣(測試組)

## 4. Existing Backtesting —— **無 look-ahead bias**

已驗證的不變量(`tests/test_portfolio_parity.py`):

- 第 i 日**收盤**決定權重 → 第 i+1 日**開盤**成交 → 報酬算到第 i+2 日開盤
- 前向與回測**共用同一個規則函式**(不是兩份實作)
- 成本只有一個來源,`paper.py` 不得自己寫常數
- 基準與組合用**同一個**資金費來源

**已知的偏誤(已量化,未消除):**
- **倖存者偏誤**:7 幣是今天還活著的。逐時點篩選實測顯示
  訓練段 Calmar 2.06(後見之明)vs 0.00(無後見之明)。
  **CLAUDE.md 已註記回測 Calmar 1.33 為上限而非期望值。**
- 只有一個市場週期(2.7~3.3 年)

## 7. Paper Trading 可靠度

**可靠,而且今天大幅補強。** 2026-09-09~10 修掉八個機制錯誤:

1. 七個持倉的**數量精度全錯**(真派單會全部被拒)
2. **滑點被記成手續費**(導致開倉均價、強平價、ROI 全錯)
3. 資金費用**估計值**而非交易所實際結算(少收年化 1.74%,UNI 連正負號都相反)
4. 風險數字用**最新價**而非標記價
5. 平倉可能留**殘倉**且永遠清不掉
6. 部分成交會記成全額
7. **強平只寫 log 不平倉**(UNI 虧到 −175% ROI 仍持有)
8. **20× 槓桿讓六個倉全在懸崖邊**(BNB 距強平剩 0.14%)

**現況:** 178 項交易所一致性徹查全過,含官方文件範例逐條對答案。

## 9. ⚠ 必須先講:Master Prompt 的一個核心假設,今天被否證了

Master Prompt 第 25~31 節假設:**更多指標 + 多 Agent 投票 = 更好的訊號**。

**2026-09-09~10 實測 12 個假說,12 個全部失敗:**

| 測了什麼 | 結果 |
|---|---|
| 15 分鐘動能(3,247 筆) | 負期望 |
| 離均線距離排名 | 輸給等權 |
| 交易池擴充(固定 21) | 兩段皆輸 |
| 橫斷面動能(動態池) | 三條判準全滅 |
| 資金費收租(純永續) | 兩段皆負 |
| **擺動結構反轉** | 輸給 50MA |
| **RSI(14,30/70)** | 輸給 50MA |
| **MACD(12/26/9)** | 輸給 50MA |
| **布林通道(20,2σ)** | 輸給 50MA |
| **唐奇安通道(20/10)** | 輸給 50MA |
| **成交量突破(20,2×)** | 輸給 50MA |
| **ATR 突破(14,1×)** | 輸給 50MA |

**現行的 50 日均線在訓練段贏過全部 7 個候選訊號。**

同期查到的**機制錯誤 8 個,8 個全部是真的**。

**這個不對稱是本報告最重要的發現:**
> 瓶頸不在「訊號不夠多」,在「執行是否正確」。
> 加十二個 Agent 去投票十二個各自無效的訊號,得到的是十二倍的運算成本
> 和同一個結論。

**建議:** Multi-Agent 架構仍值得建,但**目的應該是風險控制與可解釋性,
不是提高勝率**。第 30 節的 Agent 07(Risk Manager)與 Agent 11
(Self Review)有明確價值;Agent 02(Technical Analyst)在證據上沒有。

## 15. 兩個必須由執政官裁決的問題

**Q1. 是否申請 BingX 唯讀 API 金鑰?**
沒有它,Phase 3~7 全部做不了,而且維持保證金分層、逐幣槓桿上限
永遠無法查證。（唯讀權限不能下單、不能提現。）

**Q2. Win Rate 70~80% 的目標怎麼處理?**
現行系統實測月勝率 48.5%、日勝率 40.8%——這是趨勢跟隨的本質。
70% 月勝率需要 Sharpe ≈ 1.8,而那需要**約四條彼此不相關的收益來源**,
不是更準的訊號(12 個假說已證)。
建議把目標改寫為 **Positive Expectancy + Risk Adjusted Return**,
與 Master Prompt 第 2 節的原則一致。
