# 預先登記:資金費收租(第二條腿)

**登記日期:** 2026-09-09
**執政官裁定:** 依建議執行
**狀態:** 已登記,**尚未執行任何測試**

---

## 為什麼是這一條,而不是再找一個訊號

2026-09-09 當日測了四個「找更好訊號」的假說(15 分鐘動能、離均線
距離排名、交易池擴充、橫斷面動能),**全部失敗**。同日查到的四個
機制錯誤(數量精度、滑點記成手續費、資金費用估計值、標記價用錯)
**全部是真的**。這個不對稱說明:邊際價值不在找訊號。

真正可靠的改善是**加入不相關的收益來源**——兩個 Sharpe 0.7、
彼此不相關的策略合起來 Sharpe ≈ 1.0(開根號相加,因為不會同時虧)。

資金費是最好的候選,因為它**不預測價格**,所以跟趨勢腿天然不相關,
不是碰巧不相關。而且**付款人明確**:願意付錢維持槓桿部位的人。

## 假說

在現役 7 幣內,做多資金費最低的幣、做空最高的幣(等額多空),
收取費率差,可以得到一條與趨勢腿不相關、且扣成本後為正的收益流。

## 為什麼不做經典版本(現貨多 + 永續空)

那個版本完全對沖價格風險、可收滿約 8%/年。但本系統的帳本是**純永續**,
沒有現貨。要做需要擴充帳本到現貨,那是另一件工程。
本次測的是**在現有工具內能做的版本**,並誠實承認它保留了價格風險。

## 規格(測試前寫死,不得事後搜尋)

| 項目 | 值 | 為什麼不是搜出來的 |
|---|---|---|
| 交易池 | 現役 7 幣 | 與現行系統一致,不引入新的交易池問題 |
| 排名依據 | 最近 3 次結算(=過去 24 小時)的費率合計 | 決策當下真的知道的資訊,無前視 |
| 做多 | 費率最低的 3 個 | 7 個取對稱的 3/3,中位數那個不碰。不是搜出來的 N |
| 做空 | 費率最高的 3 個 | 同上 |
| 權重 | 各邊等權,多空名目相等(美元中性) | 無自由參數 |
| 重排頻率 | 每日 | 與決策頻率一致 |
| 成本 | `portfolio.costs` 實測值,每次換手全額計入 | 不得假設換腿免費 |

## 事前量到的規模(供判準對照,非判準本身)

- 橫斷面資金費價差:中位 **13.96 個百分點/年**(333 天實測)
- 多空價差的價格波動:年化 **38.5%**(SOL/BNB 配對)
- 成本前訊噪比:**0.362**

## 通過判準(**測完不得修改**)

1. **訓練段與驗證段,扣成本後淨報酬都必須為正**
2. **與趨勢腿的日報酬相關性 < 0.3**
   —— 這條是關鍵。一條賺錢但跟現有策略高度相關的腿,提升有限。
   本測試問的不是「它賺不賺錢」,而是「**它值不值得加進來**」。
3. **合併組合(趨勢 + 資金費,各半)的 Sharpe,在兩段都必須高於
   趨勢腿單獨的 Sharpe**

三條全過才算成功。任一條不過即放棄。

## 明文禁止的事後行為

- 不得調整多空各取幾個後重測
- 不得調整排名窗口(3 次結算)後重測
- 不得調整重排頻率後重測
- 不得換切分點後重測
- 不得只報告贏的那一段
- 不得在失敗後改成「只做空、不做多」之類的變體再測

## 已知限制(必須與結果一起報告)

1. **資金費歷史只有 333 天**(2025-10-11 起),受交易所端點上限。
   訓練/驗證切分後各約 222 / 111 天 —— **樣本很短**,
   任何結論的證據力都受此限制。
2. **價格風險未對沖。** 多空兩腿會分岔,而分岔的波動(38.5%)遠大於
   能收到的費率差(13.96%)。這是本策略真正的風險來源。
3. **這 333 天只涵蓋一個市場階段**(主要是下跌段)。
4. 近 90 次結算七個幣全為正費率,其中四個被釘在交易所基準費率
   +0.010000% —— 費率離散度可能隨時間收斂,歷史離散度不保證延續。
