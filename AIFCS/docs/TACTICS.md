# 戰術手冊 — 1v1 機砲纏鬥，對準我們的規則

> 來源：美國空軍 F-16 戰技手冊 AFTTP 3-3 Vol 5（1999，SRC-022）、AETC TTP 11-1 的 BFM 概念（SRC-023）、
> 海軍 T-45 ACM 講義（SRC-016）、DARPA ADT 兩隊論文與賽評（SRC-018～020）、韓國冠軍（SRC-012）。
> 這份是**設計層**：給人讀、給腳本對手、給課程和評測用。不直接進模型；要用就走 `experiments/`。
> 所有數字是 F-16 真機手冊或模擬賽的，和 JSBSim 的 F-16 相近但不相等，當量級看。

## 0. 先把我們的規則翻成戰術語言

| 規則 | 戰術上的意思 |
|---|---|
| 只有機砲：鼻軸線 2° 全角（半角 1°）、500–3000 ft | 等於 ADT 的 WEZ。沒有飛彈，所以**沒有「進飛彈射程就脫離」這回事**，手冊裡所有關於飛彈的段落都不適用；只剩手冊的「機砲攻擊」與「機砲防禦」兩章 |
| 擊殺 = 錐內**累積** 3 秒，不需連續，不分遠近 | **多次短暫的 snap 加起來也算**。ADT 近距離傷害大、遠距離小，我們不分；所以 2,900 ft 的 0.5 秒和 600 ft 的 0.5 秒等值。高角度 snapshot 在我們的規則下比在 ADT 更划算 |
| 沒擊殺比分差：Σ(TA_norm + AA_norm)×DF，每幀 | 分差在獎勵「在他後面」（AA 小）和「鼻子對著他」（TA 小）兩件事，**各自獨立給分**。HOST 實測 90° 以內就有半分，所以「待在他後半球」本身就值錢 |
| 距離因子 150–500 m ×1.2、500–1500 m ×1.0 | 甜區 150–500 m（490–1,640 ft）落在機砲射程內。手冊說 1,000–2,000 ft 是「舒服的致命射程」，兩邊一致 |
| 超過 9 G 扣分；<50 m 墜毀；<15 m 相撞 | 手冊的 G 上限是 9，一樣。手冊裡「1,000 ft 硬地板」我們沒有，地板是 50 m，更低，但地面防護層一樣要有 |
| 300 秒 | 手冊：「贏下頭兩圈的人會很失望」，高角度戰要好幾個 pass 才分出來；300 秒夠打 6–10 個 pass |
| 公開版 HOST 開局：相反航向、並排、1.7 km、同高、340 kt | 這是手冊「高角度 BFM」的起手式（single-side offset high-aspect encounter），不是攻守局 |

## 1. 幾何語言（AFTTP 3-3 4.3.2；AETC TTP 11-1）

- **四個量**：距離 range；**AA** aspect angle = 從目標機尾量到攻擊者位置的角（和攻擊者航向無關）；**HCA／angle-off** = 兩機縱軸夾角；**ATA** antenna train angle = 目標偏離我鼻軸線的角。公告的 TA 就是 ATA，公告的 AA 就是手冊的 AA。
- **三條追擊線**：lead（鼻子指在他前面，射擊時）、pure（指著他，閉合最快但會 overshoot）、lag（指在他後面，拉開距離不 overshoot、建 turning room）。鼻子在不在他的運動平面（POM）裡決定用鼻子還是升力向量判讀。
- **轉彎圈 Tc 與轉彎室 Tr**：第四代戰機最大性能轉彎半徑約 3,000 ft，Tc 約 6,000 ft。手冊公式：半徑 = V²/(g·G_radial)，轉率 = 1,092·G_radial/KTAS（V 用 KTAS，g = 32.2）。
- **F-16 沒有單一 corner velocity**，是 330–440 KCAS 的「corner plateau」；170–330 KCAS 半徑幾乎不變；>440 KCAS 半徑急增。最大 G 時 >350 kt 攻角 10–15°，<350 kt 攻角約 25°（機頭指向比實際航跡「多轉」這麼多——讀軌跡時要扣掉）。
- **Control zone**（AETC TTP 11-1）：斜距 2,500–4,500 ft、目標機尾後 25°–45° 錐內。在這裡對方做什麼都甩不掉你。注意它**比我們的機砲區遠**：控制區是「保持優勢」的地方，射擊要再進到 500–3,000 ft。
- **10° 航向差 = 入口處 1,000 ft 的側向轉彎室**（4.3.9.4.1）。入口錯了很難補。
- **進入 Tc 的速度**：450–480 KCAS，快了（480+）就微爬 500–1,000 ft 換高度優勢。

## 2. 攻擊（Offensive BFM，4.3.9）

目標順序：**殺 → 保持攻勢 → 進 WEZ → 有效射擊**。每一刻問自己「我是不是太近、角度太大？」是的話先解角度、保距離，不急著射。

1. **辨認在不在他的 Tc 外**：他在你視野裡「原地旋轉、橫向移動少」= 你在圈外；他能一直轉、AA 一直變大。圈外先射有把握的，沒有就往入口飛。
2. **入口**：指向 lag entry window（他起始位置內側一點），「飛到他剛才在的地方」。
3. **到圈上**：450–480 KCAS，到圈上才做大動作。
4. **高角度射擊的壓迫**（4.3.9.7.1.2）：熟練的射手可以壓到 **2,000 ft** 才 reposition；保守的在 3,000–4,000 ft 就脫。壓得越久對方越得 jink，越可能給你低角度的下一次機會。
5. **閉合率經驗法則**：閉合速度不超過距離的 5%：3,000 ft 時 150 kt、2,000 ft 時 100 kt、1,000 ft 時 50 kt，除非這是最後一擊、接受 overshoot。
6. **對 jink 的目標**：不要硬跟（10°/s 的滾轉 pipper 本來就跟不上），**預判他出 jink 的位置**，在那個平面先把鼻子放到 lead，等他出來就射。閉合沒控制好就利用他的 jink 減速或拉距離；他 jink 時你做「更大、同向」的動作，但別讓他離鼻子超過 25°。重複到擊殺或守不住攻勢。
7. **射程**：1,000–2,000 ft 舒服致命；越近誤差越小。致命 burst 1–2 秒。

## 3. 防守（Defensive BFM，4.3.10）

目標順序：**活下來 → 給他幾何難題 → 抓他的錯**。手冊明說「不 jink 會死，死人不能反轉」。

- **唯一的避難所**是貼近：在他鼻子（機砲區）之外、讓他沒法把鼻子放到你身上。沒有飛彈的世界裡「拉開距離跑」也沒用——他會追上（這和手冊理由不同，結論相同）。
- **出平面 jink 的時機**（4.3.10.4.3.2）：看到他明確拉 lead 就開始滾；AA 太大看不出 lead 就以 **3,000–4,000 ft** 斜距為準。升力向量偏離他 45–60°，**向下**拉 1–2 秒（向下總 G 大），再拉回到他下方建新的平行平面、累積 HCA。太早他有時間重新解平面，太晚他已經射完。
- **Rolling duckunder**（4.3.10.5.5.1）：需要 1,000–1,500 ft 高度。往正在轉的方向滾到倒飛、放鬆拉桿、滾到 90° 坡度，決定出來的方向。目的：連續改變他需要的 POM、製造閉合問題。可以一直做到沒高度或他出問題。
- **Nose-counter**（4.3.10.5.5.3）：他鼻子快到 pure pursuit 前，推桿卸載、全副翼 180° 反轉、出平面拉。要在他預計的 lead point 之前離開「他以為你要去的那片天空」，又不給他時間修正。
- **利用 overshoot**（4.3.10.5.7）：看 LOS rate。LOS 高（近、快、HCA 大）→ 卸載滾到 Lv-on 反轉，變成**一圈戰，半徑小的贏**；LOS 低 → 把鼻子拉高減慢前進、滾向 overshoot 方向，高度變成只有你有的轉彎室；LOS 很低且 HCA／距離都在控制中 → 繼續硬轉把他困在 lag。
- **合併時被 overshoot**（4.3.10.4.2）：同向繼續轉會被他的轉率解掉；**反轉**（卸載、180° 滾、Lv 略低於他、AB 限制器拉）讓他的大半徑把他推到你 3/9 線前，除非他立刻減速——那也好，戰況中和了。
- 低角度防守後的跟進：鼻子低 10–15°、動力收到 idle、維持 160–180 kt（在機砲纏鬥的最小半徑區）。

## 4. 高角度 / 合併（High-Aspect BFM，4.3.11）— 我們的開局就是這個

- 先在下一個 pass 前判斷自己是**贏轉（累積角度）、輸轉、還是平手（pass 時 HCA 180°）**。
- **合併前的轉彎室只有對方給你才有**。對有警覺的對手，pass 前偏移沒意義；硬要在 pass 前留鼻子，等於送他一個 lead turn。前兩個 pass 通常沒有經典 lead turn 的機會，優勢被 Tc 收縮和平均轉率抹平——**等**，等他碰到性能極限。
- **合併時的間距**：想打**兩圈戰**（比轉率）就盡量拉大橫向偏移；對方如果不理，180° 後的**一圈戰**（比半徑）會讓你佔大便宜。
- **合併時的高度差**就是能量差，只有兩機之間的高度差有意義。
- **ADT 的 AI 怎麼打合併**：Heron 從一開始就狠拉，對頭、側面高角度射擊，人類飛行員受真實世界防撞訓練不敢這樣（SRC-019、020）。在我們「累積 3 秒、不分遠近」的規則下，這條路比在 ADT 還划算；公開版 HOST 的開局（相反航向並排 1.7 km）第一個 pass 就會出現。
