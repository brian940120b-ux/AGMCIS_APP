## 你實際上在寫什麼

**一個 UDP 客戶端。** 就這樣。

```
HOST ──── 208 bytes，每秒 60 次 ────→  你的程式
          26 個 double：
          自機 20 個（經緯度、高度、姿態、
          速度、角速度、過載、攻角…）
          敵機 6 個（經緯度、高度、三軸速度）

你的程式 ──── 30 bytes ────→ HOST
          5 個 float32 + b"PLAYER_CMD"
          副翼、升降舵、方向舵、油門、狀態
```

**你只能送四個數字。** ✅

「攻擊」不是你發射什麼 —— 是 **HOST 自己算**的幾何條件。你的工作單純是把飛機
飛到對的位置，機首指向對的方向。

> 這一點對我們很重要：AIFCS 從頭到尾**沒有、也不會有**任何武器控制、瞄準或
> 導引功能。比賽介面本身就不需要。

### 連線流程 ✅

`player_state` 0 → 1 → 2 的握手，實測 33,090 幀零錯誤。

## 怎麼算贏

### 第一順位：擊墜 📄

機首對準敵機、在距離帶內、**累積**三秒 → 立刻結束，**無視當下任何分數**。

```
攻擊成立條件：追蹤角 ≤ 1°（D 級判讀，見 CONFORMANCE.md）
              距離 500–3000 ft
              累積 3 秒（不用連續）

S_kill = 1000 + (300 − 達成秒數)     ← 越快分越高
```

### 第二順位：還活著 📄

| 結局 | 判定 |
|---|---|
| 一方墜毀（< 50 m） | 另一方贏 |
| 相撞（< 15 m） | 比優勢分 |
| 兩方都墜 | 比優勢分 |
| 時間到 | 比優勢分 |

### 第三順位：優勢分 📄

```
S_advantage = 2000 × 攻擊秒數
            − 1000 × 超過 9G 的秒數
            +   10 × Σ 每幀位置分

位置分 P(t) = (追蹤角分 + 方位角分) × 距離係數
```

**距離係數**（規則用公尺）：

| 距離 | 係數 | |
|---|---|---|
| < 150 m | 0.1 | 太近，有撞機風險 |
| 150–500 m | **1.2** | **最佳** |
| 500–1500 m | 1.0 | 有效交戰 |
| 1500–3000 m | 0.5 | 戰術 |
| > 3000 m | 0.1 | 只能算偵察 |

## 從規則推出來的三件事

### 1. 甜蜜點是 152–500 公尺

攻擊包絡從 500 ft（152 m）開始，最高距離係數到 500 m 為止。
**中間那段同時吃到兩個好處。** 算出來的，不是猜的。

### 2. 9G 很貴

**每秒扣 1000 分**，而追蹤一秒才賺 2000 分。硬拉會把賺的吐回去一半。

### 3. 遠距離對準沒有用

超過 3000 公尺，位置分只剩最佳值的 1/12，而且完全不可能擊墜。
把鼻子從兩英里外對準敵機，在比賽裡幾乎不值錢 —— 但**主辦方自己的訓練獎勵
會給滿分**（見 `TUNING.md`）。

## 不能做的事 📄

規則 7–11 禁止：網路攻擊、封包竄改、掃描、干擾。

**AIFCS 本來就沒有這些功能，也不會加。** UDP 層純粹是模擬傳輸。
