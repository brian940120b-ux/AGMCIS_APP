## D：原本的四個判讀 — 三個確認，一個更正

### 1. 攻擊錐半角 1° — ✅ **確認**

原文：「有效攻擊範圍：**鼻軸線 2 度**距離 500-3000 呎」

兩項獨立證據都指向半角 1°：

- **圖 4**：箭頭橫跨**整個**錐標「2°」
- **主辦方自己的程式** `jsbsimEnv.py:406`：`on_target = own_3d_angle <= 1.0`
  （`own_3d_angle` 是追蹤角，依定義就是半角）

### 2. `ΣP_t` 每幀累加 — ✅ **確認**

原文寫 `P_t：即時位置優勢指標`，「即時」= 每個運算幀。模擬時脈 60 Hz。

### 3. `T_G` 是超過 9G 的秒數 — ✅ **確認**

原文：`T_G：實際超過 9G 值秒數`，取自表 1 第 15 欄
`accelerations/n-pilot-z-norm`（本機飛行員 Z 軸 G 值）。

### 4. 方向舵 — ⚠️ **更正：規則是 ±1，不是 ±0.2**

原本我寫「整形的 ±0.2 才是誠實的那個」。**不對。**

| 來源 | 值 | 性質 |
|---|---|---|
| **表 2（規則）** | **−1 ~ +1** | ← 這才是規則 |
| 範例連線程式 | clip 到 ±0.2 | 範例自己的選擇 |
| 範例訓練動作空間 | `[0, 1e-17]` | 範例自己的選擇 |

整形程式在 `player1_Loadmodel.py` —— **參賽者的程式**，而公告說明 五.3.(2).C
明文允許改寫。詳見 `TUNING.md`。

## E：沒驗證過（風險）

### ⚠️ 最高風險：回合開始時飛機有沒有配平

我們（照抄參考套件）**沒有呼叫配平**。IC 只設 `theta=0, phi=0` 就跑。

實測我們的環境，搖桿置中、油門保持 0.8：

```
 t=5s   14,367 ft  pitch  -7.6°  388 KCAS
 t=20s  10,662 ft  pitch -20.0°  554 KCAS
 t=49s     164 ft  pitch -16.1°  694 KCAS   → 墜毀
```

**搖桿置中 49 秒撞地。** 每個策略都得先學會「拉桿活下來」，才輪到學打仗 ——
這極可能就是我們 122,880 步的模型 0/6 全部墜毀的原因。

**這和參考套件一致，但和真實 HOST 一致嗎?不知道。** 如果 HOST 會配平而我們不會，
我們就是在訓練一架不存在的飛機。

**怎麼驗證（需要 HOST）：** 用探針送**純中立指令**（搖桿置中、油門 0.8），看 HOST
那架飛機是保持高度還是像我們一樣低頭。保持 → HOST 有配平，我們要補。

## F：對真實 HOST 的計分欄位逐幀核對（2026-10-01，v6 一回合，18,002 幀）

主辦方公開版 HOST（`JSB_host_GUI_publish.exe`）每幀把兩機狀態和它自己的分數欄位寫進 CSV。用 CSV
裡的位置與姿態重建 TA／AA／距離因子，和它的 `AttackAdvantage`、`PositionAdvantage`、
`FinalAdvantage` 三欄逐幀比（工具：`backend/competition/hostcsv.py`，固定樣本 6 列在
`backend/tests/data/`）：

| 欄位 | HOST 實際算法（36,000 個值，最大差 0.0000） | 公告 p.9 寫的 | 狀態 |
|---|---|---|---|
| AttackAdvantage(t) | `DF × (180−TA)/180`，TA ≥ 90° 為 0 | `(90−\|TA\|)/90` | ⚠️ **衝突 C11**：門檻同（90°），斜率不同；90° 以內 HOST 多給一半 |
| PositionAdvantage(t) | `DF × (180−AA)/180`，AA ≥ 90° 為 0 | `(90−\|AA\|)/90` | 同上 |
| FinalAdvantage | 每幀累加 `Att + Pos`，**含 START 前的保持幀**（448 幀 × 0.25 = 113 分，雙方都有） | `W_pos·ΣP_t`，W_pos 參考 10 | ΣP_t 每幀累加 ✅（U05 關）；有效 W_pos = 每幀 1（U 新） |
| TA／AA 定義 | 3D；TA 用機頭（yaw/pitch），不是速度向量；AA = 敵機機頭方向與視線夾角，在其正後方為 0 | 同 | ✅ |
| 距離因子 | 表 4 的公尺分段 | 同 | ✅（唯一一幀差 0.05 在 AA = 90.0 剛好的邊界） |
| T_att、T_G | 這回合都是 0（沒進錐、沒超過 9 G），**W_time、W_G 仍未知** | — | ⏳ 要一回合有進錐／超 G 的 HOST 記錄 |
| 擊殺 | `RemainingHP` 180 起跳、不扣 | 累積 3 秒 | 180 = 3 s × 60 Hz `[INFERRED]`；未觸發 |

程式碼：`scoring.Normalisation`（`announcement` 預設、`host` 實測），`SideScore(normalisation=…)`。
**預設沒改**：比賽日 HOST 是不是這個版本未知，改預設要人決定。
